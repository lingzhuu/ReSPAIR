# 修改后的模型：低秩混杂 + 稀疏成对联系

这份文档是《我们的联合模型：问题评估》（同目录）第一条建议的具体写法，可以直接替换提案里“我们的思路”第 1、2、4、5 点。

## 核心改动（一句话）

原模型：共享隐藏模式 = 联系。
新模型：**所有隐藏模式（不管共享还是私有）都当作组织结构/混杂；联系是扣掉这些之后，基因和代谢物残差之间剩下的、稀疏的成对关系。**

用比喻说：先把“富人区”“学区”“老城区”这些所有能影响大量设施分布的区域效应（不管有没有标注）都扣掉，然后看在同一个区里，**这一个**网球场多出来的那部分，是否对应**这一个**超市多出来的那部分。

---

## 1. 模型

$$
\begin{aligned}
G &= Z B_g^{\top} + F \Lambda_g^{\top} + E_g \\
M &= Z B_m^{\top} + F \Lambda_m^{\top} + E_g W^{\top} + E_m
\end{aligned}
$$

| 符号 | 含义 | 与原模型的区别 |
|---|---|---|
| Z, B_g, B_m | 已知组织结构及其效应 | 不变 |
| F（n × K） | **所有**隐藏空间模式，K 一般 10–50 个，每列一个高斯过程，各有自己的长度尺度 ℓ_r | 不再分共享/私有，统一当作混杂 |
| Λ_g, Λ_m | 每个分子对各隐藏模式的载荷 | 只用来扣除，不再用来定义联系 |
| E_g | 基因的“局部残差”：扣掉已知结构和所有隐藏模式之后，这个格子里该基因比预期多出/少出的部分 | 新的关键量 |
| **W**（代谢物 × 基因） | **稀疏的成对联系矩阵**。W_kj ≠ 0 表示：基因 j 在某处比预期高时，代谢物 k 在那里也比预期高（或低） | 新增，是要检验的对象 |
| E_m | 代谢物的残余噪声 | 不变 |

由模型推出基因 j 和代谢物 k 在同一位置的协方差：

$$
\mathrm{Cov}(g_j, m_k) = \underbrace{\textstyle\sum_r \lambda_{g,jr}\lambda_{m,kr}}_{\text{低秩：混杂/大程序}} \;+\; \underbrace{\sigma^2_{g,j}\, W_{kj}}_{\text{稀疏：成对联系}}
$$

整张联系表就是 **C = Λ_g Λ_mᵀ + W D_g**（D_g 是基因残差方差构成的对角阵）。低秩部分扣掉，只检验 W 的单个元素。

**为什么写成“代谢物依赖基因残差”而不是对称的形式：** 生物学上是酶决定反应速率、进而影响代谢物，方向自然；而且这样写，W 在协方差里就是严格稀疏的一块，好估计也好解释。以后需要也可以加对称版本。

## 2. 可识别性：靠什么把混杂和联系分开

这是新模型必须讲清楚、也是审稿人一定会问的地方。区分依据只有一条：

> **混杂是“普遍的”，联系是“稀疏的”。** 一个隐藏因素（缺氧、血管、未标注区域）会同时影响几百上千个基因和许多代谢物，所以它能从 3 万个基因里被可靠地估计出来；一对酶–代谢物的联系只涉及一个基因和少数几个代谢物，不足以形成一个隐藏模式。

统计上这对应“低秩 + 稀疏”分解的可识别条件（Chandrasekaran 等 2011/2012）和基因组学里的混杂校正理论（CATE：Wang、Zhao、Hastie、Owen，Ann. Stat. 2017；FarmTest：Fan 等，JASA 2019）。基因数量多（p ≈ 2–3 万远大于 K）正好是这类方法最有利的情况。

**要在提案里诚实写出的代价：** 如果一个真实的生化关系本身是“普遍的”（例如 HIF 驱动整套糖酵解基因和乳酸一起升高），它会被归到低秩部分、被当成程序扣掉。新模型找到的是“**超出整体程序之外的、成对特异的**”联系。这个定位比原来更窄，但更站得住，也更接近“局部化学反应”的本意。

## 3. 怎么估计

分两版，对应提案第 5 点“先简单版再完整版”。

### 简化版（先做，几天能跑通）

1. **拟合混杂模型**：把 G 和 M 拼在一起，拟合 `[G, M] = Z B + F Λ + 残差`。可以先用 GLM-PCA / 负二项因子模型处理计数（基因），代谢物做 log 变换；空间平滑先不加，或者用现成的 MEFISTO / NSF 得到带 GP 的 F。
2. **取残差**：Ê_g（n × 3 万）、Ê_m（n × 1000），用 Pearson 残差。
3. **一次矩阵乘法得到所有配对的统计量**：T = Ê_gᵀ Ê_m（3 万 × 1000）。
4. **对每一对做空间校准**（见第 4 节），得到 p 值。

因为扣掉混杂后，基因残差之间基本不相关（D_g 近似对角），这里的“边际”残差相关就等价于 W 的元素是否为零，不需要对每个代谢物做 3 万维的回归。原提案“拟合一次、所有组合一起算出来”的优点保留了。

### 完整版（之后做）

把 F、Λ、W 放在一个模型里联合估计：F 用稀疏/诱导点 GP，W 加 L1 或 spike-and-slab 先验，基因用负二项似然。好处是 F 的估计不确定性会传递到 W，并且能利用反应网络先验（第 5 节）。

## 4. 显著性检验：同时考虑两边的空间自相关

即使扣掉了隐藏模式，残差里仍会有小尺度的空间自相关。两个都“成片”的残差，即使毫无关系，样本相关也会偏大。做法是在空间频率上分解：

1. 选一组空间基 U（规则网格用二维 DCT/傅里叶基，不规则光斑用图拉普拉斯特征向量），按空间频率从低到高排列。
2. 把残差投影上去：ĝ_j = Uᵀ ê_{g,j}，m̂_k = Uᵀ ê_{m,k}。
3. 统计量 T_jk = Σ_l ĝ_{jl} m̂_{kl}。在“两边独立”的零假设下，各频率分量近似独立，所以

$$
\mathrm{Var}_0(T_{jk}) \approx \sum_l s_{g,jl}\, s_{m,kl}
$$

   其中 s 是各自在频率 l 附近的功率（按频带平滑估计）。
4. z_jk = T_jk / √Var₀，转成 p 值。

这个方差同样是一次矩阵乘法（S_g S_mᵀ），所以 3000 万对仍然很快。这就是提案第 4 点说的“同时考虑基因和代谢物双方的空间规律”，本质是 Dutilleul（1993）修正 t 检验的多变量、可批量版本。

**我做了个小模拟检查校准**（40×40 网格，两个互相独立、长度尺度分别为 3 和 5 的空间场，500 次重复，名义水平 5%）：

| 方法 | 实际误报率 |
|---|---|
| 普通相关 | 69% |
| 频率校正，频带较粗（每带约 80 个分量） | 15% |
| 频率校正，频带较细（每带约 10 个分量） | 4.8% |

所以方法可行，但**频带宽度要细**，尤其是低频部分，否则会偏宽松。正式方法里要把这个作为一个需要模拟确定的设置。

**多尺度问题顺便解决了：** 把 T_jk 拆成不同频带的贡献，就能直接回答“这一对的联系发生在哪个空间尺度”。可识别的最小尺度由平台分辨率决定（Visium 约 100 µm 间距）。

## 5. 选隐藏模式个数 K：用负对照，而不是检验 K_s = 0

原方案的整体检验 H₀: K_s = 0 是边界上的非正则检验，现在不需要了。K 改用负对照来定（RUV 的思路）：

- **负对照配对**：生化上几乎不可能有直接关系的基因–代谢物对，例如非代谢基因（核糖体、剪接因子等）和任意代谢物，或者打乱基因–代谢物对应关系后的反应网络配对。
- **选 K 的准则**：逐步增加 K，直到负对照配对的 p 值近似均匀分布。K 太小，混杂没扣干净，负对照会出现大量假阳性；K 继续增大，阳性对照（已知酶–代谢物对）的信号开始下降，就说明在吸收真实联系了。两者之间的平衡点就是 K。
- **整体检验**改为：在候选配对上，显著配对的比例是否显著高于负对照。

**候选配对**（重点检验的那部分 W）来自反应网络：Recon3D / Mouse1 / Rhea 里，每个代谢物对应的催化酶、转运体基因。全基因组的配对也可以检验，但候选配对单独做多重检验校正，检验力会高很多。

## 6. 多重检验

扣掉混杂之后，各配对统计量之间的相关性主要来自基因残差之间的剩余相关，比原方案（整张表由 K_s 个模式决定）弱得多，BH 法基本适用。仍建议用一次“零模型参数自助法”检查：用拟合出的混杂模型、令 W = 0 模拟数据，跑完整流程，确认 FDR 在名义水平。

## 7. 对照原评估，这样改解决了什么

| 原评估的问题 | 新模型里 |
|---|---|
| 1. 未标注的共享混杂被算成联系 | 所有隐藏模式都被扣除，只在残差里找联系 ✔ |
| 2. 低秩表只能表示“同属一个程序” | 联系在稀疏的 W 里，按单对表示 ✔ |
| 3. 和 MEFISTO 区别不大 | MEFISTO 类方法只是第一步，核心贡献变成残差上的成对检验和校准 ✔ |
| 4. 参数乘积的非正则检验 | 检验的是单个 W_kj，是正则的 ✔ |
| 5. K_s = 0 的边界检验 | 改为用负对照选 K ✔ |
| 6. 3000 万个检验高度相关 | 相关性大幅降低，并用参数自助法核查 ✔ |
| 7. 双侧空间检验未设计 | 频率分解校正，已在小模拟中验证 ✔ |
| 9. 正交约束只挡线性关系 | 不再需要 Zᵀ F_s = 0；非线性的组织效应由隐藏模式吸收 ✔ |
| 10. Z 的不确定性/循环 | Z 估计不准的部分会被隐藏模式吸收；Z 主要只用于解释（部分 ✔） |
| 11. 高斯噪声 | 用负二项/Pearson 残差（需实现） |
| 12. 两边格子不同 | 仍需先把 MSI 像素聚合到 Visium 光斑范围内（未解决，完整版里可用 GP 在各自坐标上观测） |
| 13. 多尺度受分辨率限制 | 按频带分解，尺度下限按分辨率写明 ✔ |
| 8. 模拟循环论证 | 仍需设计，见下 |

## 8. 模拟验证要怎么改

核心场景：生成一个**同时影响一批基因和一批代谢物的未标注因素**（比如一个缺氧梯度），再植入少量真实的成对联系。比较：

- 普通相关、MANTIS、**原方案（共享模式 = 联系）**、新方案；
- 指标：真实配对的检出率，以及受缺氧因素影响但并无成对联系的配对的误报率。

预期原方案和 MANTIS 会在缺氧因素上大量误报，而新方案不会。把原方案也放进对比，正好在论文里说明“为什么不能把共享模式当成联系”，这本身就是一个贡献点。

另外加入：计数噪声、非线性细胞类型效应、离子抑制（一个只影响代谢物、随区域变化的乘性因子）、位置配准误差。

## 9. 需要在提案里改的风险表

| 风险 | 应对 |
|---|---|
| 真实但“普遍”的生化程序被当成混杂扣掉 | 明确定位为“程序之外的成对特异联系”；用阳性对照监控 K 的选择 |
| 混杂只影响很少的分子，无法和真实联系区分 | 这是方法的根本假设，在模拟中评估混杂“普遍程度”多低时会失效 |
| 空间校正频带设置不当导致偏宽松 | 用零模型自助法校准频带宽度 |
